# One Glossy Red Chilli

Satu cabai merah mengkilap di atas papan batu — digambar dari nol dengan Python + PIL. Cabai tunggal, permukaan licin berkilau, bayangan lembut, dan komposisi sederhana yang membuat gambar ini terasa hidup dan menggugah selera.

## Cara jalan

```bash
python3 main.py
```

Perintah di atas menghasilkan `output.png` (1024×1024, satu gambar).
