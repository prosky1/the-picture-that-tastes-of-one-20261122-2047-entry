One ingredient, one picture: a single fresh lemon slice, glistening with juice, drawn to make you taste it at first glance. `main.py` (Python 3.13, Pillow only, no network, deterministic) draws a 1024×1024 PNG — golden rind, white pith, eleven juicy segments, droplets and gloss on a dark slate backdrop — and writes it to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
